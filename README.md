# Screen Time Physiology

## Dependencies

System dependencies: `Python 3.12+` and `uv`
Python package dependencies: [`pyproject.toml`](pyproject.toml)

## Steps to reproduce

All package dependencies for this project may be installed using [`uv`](https://github.com/astral-sh/uv) by running `uv sync` in the project's root directory. This will set up a Python virtual environment capable of replicating the analysis in `screen_time_physiology.ipynb`.
